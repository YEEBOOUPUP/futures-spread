# 样例目录

- `WIND迷你示例.csv` — WIND 宽表格式的迷你示例（P 品种，close + settle 两个块），
  可用作本地双击打开页面时体验"手动上传"功能。

## WIND 宽表格式（你的真实文件：WIND价格-wyb.xlsx）

真实文件前两个工作表"国内油脂期货价格"（P/Y/OI）与"国内油料期货价格"（M/RM），
每个工作表是多块拼接（每块以"证券代码/代码"标签开始，第 6 行 Date/close 或 Date/settle 决定块类型）：

```
行1-2  开始日期 / 截止日期（每块重复）
行3    证券代码：P.DCE=主力  P00.DCE=最近合约  P01M.DCE=01月合约
行4    证券简称（中文名）
行5    指标中文（日期/收盘价）
行6    指标英文：Date/close（收盘价块）或 Date/settle（结算价块）
行7起  数据：块标签列 = 该块的日期列，其余列 = 对应合约价格
```

转换脚本 `tools/excel_to_json.py` 会按此格式自动解析（默认处理前两个工作表，
`--sheets` 可指定其它工作表）。
